# Scores

Violin II parts for the current repertoire.

| File | Piece | Edition | Complete? |
|---|---|---|---|
| `peter-and-the-wolf.pdf` | Peter and the Wolf | Kalmus, 8 pp | yes |
| `the-typewriter.pdf` | The Typewriter | Alfred 25039, 2 pp | yes |
| `the-syncopated-clock-p1.jpg` | The Syncopated Clock | Woodbury/EMI 26663 (2006 arr.) | **page 1 only** |
| `childrens-corner.pdf` | Children's Corner | Caplet transcription | yes |

The Prokofiev and Typewriter PDFs were checked page-for-page against photographs
of the orchestra's paper parts and are the same editions, so bar numbers and
rehearsal marks match what is on your stand.

## To add a page or a piece

Save the file here, then add it to that piece in `assets/data.js`:

```js
"scoreFiles": [
  { "label": "Violin II part, page 2", "file": "scores/the-syncopated-clock-p2.jpg" }
]
```

PDFs embed in the page; `.jpg`, `.png` and `.webp` render as images.

deliberately left out:
