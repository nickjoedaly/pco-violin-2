# Scores

Drop scanned Violin 2 parts here, named to match the piece id:

- `peter-and-the-wolf.pdf`
- `the-typewriter.pdf`
- `the-syncopated-clock.pdf`

Then add them to that piece in `assets/data.js`:

```js
"scoreFiles": [ { "label": "Violin 2 part", "file": "scores/the-typewriter.pdf" } ]
```

## Why there are no scores checked in

All three works are still under copyright in the United States:

- Leroy Anderson died in 1975; *The Syncopated Clock* (1945) and *The Typewriter* (1950)
  remain in copyright.
- Prokofiev's *Peter and the Wolf*, Op. 67 (1936), had its US copyright restored under the
  URAA and is not public domain here.

So there is no legitimate free edition to download and commit. Scan the parts the orchestra
already has.
